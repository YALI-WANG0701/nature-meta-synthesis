# 筛选、全文与质量评价

## 从数据库导出到人工确认子集

先识别导出平台、字段、文件编码和记录边界，保存原文件；解析失败不能成为文献排除理由。逐条保留原始记录 ID 和来源，去重到报告后再判断同样本多报告。PDF文件名不是规范题名，预印本与发表版不重复算独立研究。

计数至少区分：平台显示命中量、实际导出记录量、去重报告量、题摘候选量、请求获取正文量、未获取正文量、已评估正文量、分析报告量与独立研究量。平台只导出一部分时，不把导出量称为总命中量。后补网页来源单列；项目登记库的累计行数不是初检命中数。候选清单代号如P1不是最终纳入状态。

题摘判断使用相关性门槛，信息不足保留到正文。全文已读的内容排除与未得全文分别记录；后者用 `not_retrieved` 或当前项目等价状态，不补造内容性理由。真实流程未完成时可报告阶段计数及缺口，不能画成完整最终PRISMA流程。

用户另给人工复核PDF或改变某报告的用途时，记录当前报告集及版本，沿用既有ID。研究者确认报告集只确认其明确采纳的事项；质量、提取、编码与关系的审核状态各自保留。不得因已确认一份论文而批量将其全部分析标为人工通过。

## 主综合、拓展、背景与主体

报告用途和证据主体是两个轴，不能合为一个准入等级：

| 判断轴 | 应记录的内容 | 使用限制 |
| --- | --- | --- |
| 报告用途 | 主综合；拓展；背景；待定/排除 | 拓展先单列，再比较加入/移除；背景用于定义与讨论 |
| 证据主体 | 目标人群直接材料；间接观察者；可分离混合；理论材料 | 对学生的导师转述保持间接层，不代称学生自述 |
| 文本层级 | 参与者/交互材料；作者经验发现；作者讨论；建议 | 担忧不等于实际损害，建议不等于已发生行动 |
| 分析用途 | 实质发现；条件/反例；仅情境 | 仅情境不增加主要支持数 |

对主集、拓展和背景的安排由研究问题及用户已确定范围决定，不把本次GenAI项目的11篇、A/B命名或教育阶段变成其他项目的固定模板。

## 全文获取与阅读覆盖

确认用户是否限定仅正文；若已限定，后续不反复询问补充材料。正文内附录与另行SI分开记录，缺SI对应信息不足而非自动质量失败。使用本地副本或合法公开/机构访问；临时登录会话URL不能当稳定资源入口。需要登录时只要求完成实际必要的用户步骤，既有访问授权不重复询问。

记录正文来源、版本、取得日期、PDF页序及必要的文件校验。报告公开年份、卷期年份和DOI字符串年份可能不同，按实际元数据分别核对；读的是预印本时保留版本标签，不能以已发现发表版DOI宣称读过最终正文。仅凭失败搜索不能断言论文不存在。

长文分块时记录方法、相关结果、讨论、图表与正文附录的已读范围；PDF提取或OCR不清的表图需回看页面。无法读取的范围留待补，不用摘要补成全文评估。

## 用户指定的七维定性评价

以下是可适配的项目评价维度，不是声称Glynn原工具恰好有七条：

| 维度 | 质性/混合研究中的判断 | 避免的机械判断 |
| --- | --- | --- |
| 问题与核心概念 | 问题、术语和任务边界是否明确 | 只有题名命中便视为清楚 |
| 研究设计 | 设计、资料与问题是否适配；混合研究能否分离质性部分 | 把纯定量成效当质性发现 |
| 模型或概念贡献 | 概念、解释与已有研究的联系及证据 | 没有新变量即排除 |
| 样本 | 招募、选择理由、经验覆盖及资料充分性 | 要求所有访谈满足概率代表性和统计精度 |
| 数据采集与工具 | 资料来源、提纲/任务/测量依据、采集与研究者位置 | 把量表信效度标准原样套到全部观察材料 |
| 分析与结果展示 | 分析步骤、材料到主题的联系、实例和不一致发现 | 只看到软件名称便判规范 |
| 结论与证据 | 结论是否由结果支撑，是否承认情境和局限 | 用摘要的强结论替代正文依据 |

每项给出具体位置、判断与理由，区分已展示、有限、不清楚、设计不适用。没有原版工具或用户只给作者名、文内[19]等序号时，先确认具体文献及版本；尚未唯一确定可继续使用明确标注的项目适配维度，不误认另一个文献表中的同号引用，不声称完整实施原工具。

相关性准入、资料可提取性、方法学质量及发现信心是不同任务。质量缺陷对哪条主题/关系有影响须落实到具体贡献；不默认总分、B级阈值或按期刊索引排除。正式CERQual/ConQual等仅在实际实施且与方法适配时报告；一般边界检查不自动产生等级。

## 阶段交付

初筛交付逐条决定/建议、理由及重复关联；全文复核增加正文位置与未获清单；质量交付逐项评价及综合处置。记录已核读范围，列出人工待裁定事项。用户要求继续分析已确认子集时，先完成该子集的证据工作，同时保留总体检索尚未完成的限制。

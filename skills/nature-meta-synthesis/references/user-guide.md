# nature-meta-synthesis 用户操作指南

版本：1.1.0　更新日期：2026年10月12日

本指南帮助你从一个研究题目推进到可回查的元综合论文，也可从已有检索、人工复核、编码或草稿继续。你不需要自行编程：提供材料路径和明确任务，助手负责整理文件、维护证据表及执行可用检查；研究者负责纳入决定、重要解释和论文责任。

本次GenAI研究为流程完善提供了实践依据，但其11份主报告、拓展与背景安排、主题数量和理论选择仅属于该项目，不是其他元综合的统一要求。

## 一 先判断是否适用

适合的问题是某类学习者如何体验、实施或应对一种教育实践，哪些过程与情境能够解释差异。材料可以是质性研究，也可以是混合研究中能够定位和分离的质性部分。

如果主要目标是合并效应量、估算平均提升幅度或做文献计量，应另选相应方法。仅有摘要、一般满意度或无法定位的作者结论时，不能据此形成完整质性综合。

元综合方法、质量评价工具、报告清单和发现信心评价各有用途。例如，主题综合用于解释材料，PRISMA帮助透明报告流程；使用PRISMA并不意味着分析方法已经确定或全文筛选已经完成。

## 二 准备一个项目目录

将原始检索导出、PDF、质量工具及范文放在研究项目的材料目录，不放进skill安装目录。输出另存，保留原文件。可以让助手先建立项目，不必自己创建所有表格。

| 你已有的材料 | 本轮可以从哪里开始 |
| --- | --- |
| 只有题目和投稿方向 | 问题界定、方法与检索方案 |
| 已有CNKI、WoS等导出 | 记录解析、去重与题摘筛选 |
| 人工复核的论文正文 | 当前报告集确认、全文相关性与质量复核 |
| 已有证据表和编码 | 概念比较、主题及关系综合 |
| 已有解释框架 | 回读、反例、替代解释及结论边界 |
| 已有结果和过程记录 | 论文初稿、引用核验及格式转换 |

建议在同一项目中持续工作。换会话时提供项目目录，要求读取`project-state.md`及当前方案和权威数据；不要只复制上一轮总结而丢失证据表。

## 三 启动或续接时可以直接这样说

**从零启动**

```text
使用 $nature-meta-synthesis，帮我开展关于【研究主题】的元综合研究。
目标期刊方向为【教育学CSSCI/具体期刊】，对象和情境暂定为【范围】。
项目目录为【路径】。先判断方法与证据是否适配，形成研究问题、
纳排标准和检索方案。缺失信息先标为暂定，不预告研究结果。
```

**继续已有项目**

```text
使用 $nature-meta-synthesis，继续【项目路径】中的研究。
请先读取项目状态、最新方案和当前分析表，说明已完成与未完成事项，
从【本轮阶段】继续，沿用既有文献和证据ID，不重做已经完成的工作。
```

你若已明确某项范围或授权，可以直接说明。助手应采用已有决定继续，不因每轮重新开始而重复询问。

## 四 第一步 明确问题与方法

你提供研究主题、对象、情境、希望解释的问题、投稿方向和已有文献。助手应把宽泛话题缩小为可由资料回答的核心问题，检查已有综述与原始质性材料，并说明为何选择主题综合、案例元综合或其他方法。

你重点核对：问题是否与教育实践有关，是否把资源便利、作品表现、体验与能力发展混成同一种结果，范围是否过宽。文献篇数较少不自动否定研究，结论必须随证据范围调整。

本步应收到项目简表、研究问题、暂定证据边界与方法理由；尚未读全文时只形成暂定可行性判断。

## 五 第二步 制定标准并执行检索

先明确对象、现象与任务、设计、时间、语言、文献类型及全文要求。期刊属于CSSCI只说明投稿定位，不意味着只纳入CSSCI论文，也不意味着可以用期刊索引替代质量评价。

在本次GenAI项目中，拟定过CNKI、Web of Science Core Collection、ERIC、APA PsycInfo和Scopus五库方案。其他题目应按覆盖和访问条件选择来源；平台或入口不同，字段语法可能不同，不直接复制另一平台的式子。

```text
请依据已定研究问题和纳排标准，形成适合【数据库及实际平台】的检索式。
分别给出概念块、完整式、必要补检和已知相关论文的召回核查方法。
未实际执行的检索标记planned，不填命中数。
```

执行后保存完整检索式、字段、限制、实际日期、平台命中数和原始导出。若只导出部分结果，同时保留实际导出量。收件日期、文件名时间戳或助手操作日期不能代替真实检索日期。

助手不能登录订阅库时可以先交付检索式，由你执行后把导出文件交回。网页寻源是补充路径，不能代称订阅数据库的完整检索。

## 六 第三步 初筛 全文复核与质量评价

**交回检索导出**

```text
这是【路径】中的数据库导出文件。请按当前方案解析、去重和题摘初筛，
逐条保留记录、理由和来源。信息不足保留到全文，分开平台命中、
导出记录和去重报告，不把初筛建议写成最终人工决定。
```

**交回人工复核全文**

```text
我已人工复核这些候选，正文在【路径】。本轮范围为【仅正文/正文及SI】。
请继续全文相关性与质量复核。区分学生直接材料、教师/导师转述、
作者发现与讨论；没有得到全文的论文继续记为未获取。
```

**采用七维评价时**

```text
请按本项目七维规则评价：问题与概念、设计适配、概念或模型贡献、
样本选择与充分性、资料采集与工具、分析与结果展示、结论与证据联系。
每项给出正文位置、判断和理由；对质性设计作适配，不计算默认总分。
工具原出处或版本未核定时明确标为项目适配标准。
```

如希望使用特定作者提出的工具，提供完整文献信息或原始工具；只写Glynn或姜婷婷等[19]不足以唯一识别版本。不要把另一篇论文的同号[19]当作你指定的来源。

你应核定全文相关性、主体、研究设计及异常样本口径；不用新变量、概率代表性或统计精度机械排除质性研究。质量较弱材料如何影响某项解释，比简单打总分更有用。

本步应收到逐条筛选表、正文获取/未获清单、重复报告关联、逐项质量评价及待裁定事项。未获正文不是内容性排除理由，人工给出的子集也不证明全部候选已完成全文筛选。

## 七 在提取前明确当前报告集

可将报告列为主综合、拓展和背景；同时记录其证据主体。教师或导师论文被放入主集后，仍不能改写为学生直接经验。理论背景与邻近议题论文用于定义、比较及讨论，不能自动补齐主证据。

```text
我确认【报告清单】为主综合，【清单】为拓展，【清单】为背景。
请冻结当前报告集版本，并按实际证据主体分层。
我确认的是文献范围；新提取、编码、关系和质量判断仍需逐项复核。
```

本次项目的主11、拓展1、背景2是这种安排的示例。其他项目无需复制其数量或层级标签。若后续改变用途，记录变化原因及受影响的提取、主题和关系。

## 八 第四步 核心观点与情境提取

```text
请从当前主综合全文提取与研究问题有关的发现与情境。
分开原文、译文、原作者解释和综述者概述；保留页序、印刷页码、
主体和文本层级。支持、限制、矛盾和条件均进入证据表。
仅情境单元另标，不算主要支持；拓展与背景分开处理。
```

助手应先理解方法和完整相关发现，再逐单元提取，而非只选摘要或结论中的正向句子。表图和OCR不清部分需要回看页面；预印本、发表版和SI范围如实登记。

你可以按`evidence_id`抽查是否准确、上下文是否完整、译文是否改变含义。没有参与者原话时可以保留有资料依据的作者质性发现，但不能制造原话。原话、作者概括、建议、担忧和已发生行为不能混写。

本步应收到研究情境表、证据单元表、来源版本和阅读覆盖说明。样本人数、反思份数、交互片段数和作品数分别标明，不能相加为总人数。

## 九 第五步 概念编码与主题综合

```text
请依据已定位证据开展概念编码和主题综合。
先比较含义与情境，形成带纳入/排除边界的编码本，再形成描述性与
分析性主题。每个主题链接证据，保留反例及单报告贡献。
已有理论只作适配参照，不预设主题数量或以模型重复输出宣称饱和。
```

你应检查同名异义。例如自主可能分别指目标控制、项目责任或作品归属；输出重复也不等于学生思维重复。拆码、合码和退役映射需要记录，不能删去旧ID后重新编号而使证据链断开。

描述性主题整理材料，分析性主题回答研究问题；只有主题名称没有定义和证据不够。统计活动映射时排除退役行，累计登记量与当前支持量分开。

本步应收到编码本、赋值/修订记录、描述性与分析性主题、主题证据矩阵和反例。主题数由材料决定，不要求固定五个、九个或三级扎根编码。

## 十 第六步 关系编码与解释框架

```text
请依据主题与原文推进关系编码和解释框架。
每条关系说明来源、主体、文本层级、关系类型、支持、反例及条件；
区分局部顺序、过程联系、作者主张与综述者解释，先关系表后框架图。
独立性未核定时不填写独立研究支持数。
```

你应重点核对箭头的证据。一段局部先后不证明普遍循环，多篇报告分别出现的行为不能拼成同一学生的轨迹；不同特征共同构成一个解释概念，也不意味着已检验中介或共同配置。

框架不必画成完整闭环。只有主题结构和条件性联系时，可以保留这样的成果，不为图形完整而补造机制。

## 十一 第七步 质控 反例与结论边界

```text
请回查编码、主题、关系和关键主张的正文语境，审查概念误合并、
建议与行动、担忧与实际结果、间接与直接材料的区别。
按具体关系选择质量移除、去作者讨论、去间接观察者和关键单报告移除比较，
记录直接支持是否消失或转为解释，并给出保留、收窄、待检验或撤回的结论。
```

不是每个项目都要做相同数量的比较。选择能回答当前疑点的范围，并记录基线与保留/移除材料。比较次数不是独立实证检验次数，质量诊断性移除也不是正式文献排除。

你应看到哪些结论依赖少数报告，而不只是主题名称是否仍存在。仅剩导师解释、作者讨论或情境材料时，直接支持已经发生变化；不能据某分支保留宣称全框架稳健。

正式发现信心评价只在实际实施适配框架后报告。否则交付充分性、冲突、单报告贡献和适用范围说明，不冒称完成CERQual、专家验证或理论饱和。

## 十二 第八步 撰写CSSCI论文初稿

提供目标期刊或期刊方向、篇幅要求、中文范文和想要的格式。尚未定具体期刊不妨碍初稿，之后再按期刊规范修订。

```text
请根据最新质控后的证据、编码和框架，撰写题为【题名】的论文初稿。
参照【范文路径】的篇章与图表安排，使用教育学、教育技术学的语言，
少用不必要的引号。引用核验过的中英文权威文献，区分发现、解释和建议。
方法只写实际执行程序，提供关键主张与原文证据对照及投稿前待补事项。
```

范文可以帮助安排研究设计、跨报告主题、框架与讨论，不证明你已用过其中的软件、专家小组、留样饱和或质量等级。理论参照要解释材料，而非先套入流行概念；不能把资源便利当能力提升，把行为特征当实测心理变量。

新增讨论引用不自动成为主报告。中文与英文文献按用途选取，没有固定比例；参考文献的DOI年份与卷期年份不一定相同。关键结果应链接既有CL/E/L，便于回查和修改。

本步应收到完整初稿、主张与证据对照、书目核验及待补事项。仍缺检索、正文、工具出处或人工核定时，正文应如实保留限制，不能仅删掉局限段就当投稿终稿。

## 十三 需要Word时这样说

```text
请把已核对的初稿转换为可编辑Word，保留全文、标题层级、原生表格、
中英文摘要和参考文献。转换后核对内容一致性，并说明实际版面检查方式。
```

正常转换不应改写研究内容。文字和表格应能直接编辑，不能只是放入页面截图。源文PDF、本地版面预览和原生Word分页是不同的核验对象。若当前工具有必须渲染后交付的要求而环境无法渲染，助手应先完成转换和内容核对，说明依据与限制，再由你决定是否接受未经原生分页核验的转换稿。

只有格式转换时，不需要重新检索文献或重做概念分析。

## 十四 如何逐项人工核定

不要只说全部正确。尽量指明报告或证据ID、核对范围和修改意见，助手才能准确维护状态。

```text
我已核对E【编号】至E【编号】的原文、译文和来源位置，确认【范围】。
E【编号】的编码应改为【意见】。其他主题与关系尚未人工核定，保持pending。
请记录我的修改，并检查其对相关主题、关系和正文的影响。
```

你可以分别确认文献范围、质量条目、证据位置、译文、概念或关系；确认一层不表示其他层已经通过。`located`只说明已定位，`candidate`表示候选解释，`pending`表示待人工核查，`verified`只能在真实完成所说明的审核后使用。

没有两名人类独立评审时如实报告分工；多个AI角色或稳定生成不构成第二位人类研究者。

## 十五 看懂交付文件与继续工作

| 文件或文件组 | 你主要检查什么 |
| --- | --- |
| 项目状态与方案 | 最新范围、真实完成阶段、缺口和下一步 |
| 原始导出与检索日志 | 实际式子、日期、平台命中与导出量 |
| 筛选与质量表 | 每条决定、全文理由、未获和逐项依据 |
| 报告集与情境表 | 主/拓展/背景、主体、正文版本、样本口径 |
| 证据单元与编码 | 原文位置、翻译、含义及活动/退役修订 |
| 主题、关系与移除比较 | 哪些报告贡献何种支持、反例和条件 |
| 草稿主张与引用核验 | 正文解释能否回到证据；书目用途是否准确 |
| AI与修订记录 | 谁做了什么、何时核查、哪些仍待人工裁定 |

新模板有六张可选过程表，用于报告分层、概念赋值、修订、范围比较、引用与草稿主张。旧项目无需全部重建；让助手说明旧字段与新契约的对应关系即可。

可以要求：

```text
请运行现有结构审计和阶段统计，区分累计与活动行数、主/拓展/背景、
正文缺口和人工状态。未核定研究独立性时数量留空，不自动生成最终流程图。
```

结构检查通过只表示所查字段和链接一致，不证明原文解释正确、检索完整或人类审核已经发生。阶段输出应保留版本，旧压缩包是当时快照，不与后来修订的数据混用。

## 十六 常见情况的处理

| 情况 | 合适的处理 |
| --- | --- |
| 暂时没有全部全文 | 分开已评估与未获；分析可用子集，保留覆盖限制 |
| 缺SI | 记录仅正文，不编造提纲、编码或测量信息 |
| 只给临时登录URL | 使用稳定资源入口或本地全文；按实际访问状态记录 |
| 预印本已有发表DOI | 登记发表身份，但读的是哪版仍如实标记 |
| 少数论文支持某关系 | 明确单报告贡献，做有目的的移除比较并收窄结论 |
| 模型多次输出相同主题 | 可帮助发现分歧，不能当作正确性或饱和证明 |
| 新会话只记得结论 | 读取项目目录及最新状态，回到证据矩阵再继续 |
| 范文程序比本项目完整 | 借鉴论证安排，实际未做的步骤列为待补 |

检索、核定和投稿仍需按真实记录完成。你可以持续让助手处理可做的候选工作，但正式论文中的方法和结论必须与你实际完成的研究相符。
